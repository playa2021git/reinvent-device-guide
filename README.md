# 再発明デバイスガイド

野田中学校3年・技術科「再発明」の授業で使う、ビルド不要のWeb教材です。

## 開き方

`index.html` をブラウザで開くだけで動きます。GitHub Pagesにも、そのまま配置できます。

## ファイル構成

- `index.html` — ページ構造
- `css/style.css` — 見た目とレスポンシブ対応
- `js/devices.js` — デバイス情報（追加・修正はここ）
- `js/app.js` — 検索、フィルタ、詳細、組み合わせ、ポート割り当て
- `assets/` — 写真・MakeCode画像・接続図の差し替え先

詳細は `DEVELOPER_HANDOFF_JA.md` を参照してください。
